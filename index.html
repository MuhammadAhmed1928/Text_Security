SecureText

Web-Based Text Encryption & Decryption Tool

Vigenère

Repeating-key polyalphabetic substitution using C = (P + K) mod 26.

Autokey

Starts with a keyword and extends the running key with plaintext characters.

Vernam

Uses a key the same length as the message and applies the lecture's XOR method.

One-Time Pad

Uses a same-length key once; the lecture example uses addition modulo 26.

Caesar Cipher

Substitution cipher that shifts alphabetic characters by a selected amount.

Base64

Encodes text into Base64 representation. It is encoding, not secure encryption.

AES-256-GCM

Modern authenticated symmetric encryption using the browser Web Crypto API.

SHA-256

One-way cryptographic hash included as an optional bonus feature.
